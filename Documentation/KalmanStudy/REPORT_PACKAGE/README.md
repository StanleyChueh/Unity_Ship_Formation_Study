## Filtering methods compared (identical simulator, detector, camera, timing)

| Label in videos/matrix | What it does with the leader bounding box | Controller |
|---|---|---|
| **Kalman ON** | Kalman filter estimates leader range from box size **fused with own speed and leader speed telemetry**, plus a Kalman bearing filter; rejects detections inconsistent with its prediction (innovation gate); predicts through box loss up to 3 s | range/speed law |
| **Kalman OFF** (production) | Your current non-Kalman path: finite-difference predictor, 0.6 s hold, then lost | original area controller |
| **EMA filter** | Non-Kalman exponential smoothing + finite-difference velocity, 3 s coasting | range/speed law |
| **No tracker filter** | Raw YOLO box each frame, no smoothing, no prediction, no coasting (production bbox **track gate kept**) | range/speed law |
| **No bbox filtering at all** | As above **and** production's bbox track gate (rejects boxes jumping > 0.45 offset or > 5× area) and reacquire bias **disabled** | range/speed law |

The three bottom rows share the Kalman ON controller, so differences between them
and Kalman ON come from filtering only. Kalman OFF is your real production behaviour.

## Note on the production "Leader Detection Rate" panel

The production metric counts a frame as "detected" when the controller's `detected`
flag is set, which includes **coasting/predicted** frames. Kalman ON therefore shows
100 % through 2 s dropouts, while methods that drop the track show less. The true
fresh-YOLO-detection rate per method is in `matrix/experiment_matrix.csv`
(`fresh_detection_pct`, `correct_leader_detection_pct`).

## WL1–WL4: W1–W4 weather on a non-fixed path that completes a circle

The leader drives straight for 22 s, then makes an unexpected constant turn (0.11 rad/s, radius ≈ 164 m)
through a full 360° (complete at t ≈ 79 s; 85 s runs, leader turned 397°). Natural detection losses only.
Formation RMSE / broken time, seed 4903 (video run):

| Condition | KALMAN ON | KALMAN OFF | NO bbox filtering |
|---|---|---|---|
| WL1 rain 0.15 | **186 m / 84 %** | 380 / 91 % | 365 / 96 % |
| WL2 rain 0.25 | **360 / 88 %** | 364 / 100 % | 400 / 99 % |
| WL3 night | 560 / 96 % | **526 / 99 %** | 550 / 99 % |
| WL4 night + rain 0.15 | **405 / 96 %** | 448 / 99 % | 516 / 99 % |

All three methods fail on this path: it combines a much tighter turn than the R360 laps (the
controller already lags on tight turns, see C4) with weather that blinds the detector (night ≈ 0 %
detections). Kalman ON holds the formation longer early on in rain (WL1) but does not prevent the
loss. The older 60 s S-turn W1–W4 videos (not a circle) are kept in `rollout_videos_3way_old_nonlap/`.

## How formation error is calculated (videos and matrix)

From simulator ground truth (evaluation only; never given to the boats): leader position P_L and
planar heading unit vector f, right-hand perpendicular r = (f_z, −f_x). Each follower's slot is its
start-of-run offset rotated with the leader: left slot = P_L − 22 m·f − 13 m·r, right slot =
P_L − 22 m·f + 13 m·r. Per-follower error e = |follower position − slot| (horizontal metres; the
"L" / "R" numbers). **Formation error** = √((e_L² + e_R²)/2). "RMSE so far" = RMS of formation error
over all frames shown so far; "broken" = % of frames with formation error > 10 m. **Final RMSE**
(plot legend and matrix) = RMS over t = 15 s → end of run (first 15 s excluded: followers
accelerating from rest).

Note: the production 12-panel figures (`timeseries_metrics/`) measure "Follower Pos Error" against an
ideal equilateral triangle of side 30 m (`LEADER_TRAJECTORY_TRIANGLE_SIDE`), while the videos/matrix
use the actual ≈25.6 m start slots, so the production panels carry a baseline of a few metres even
for a perfect formation. Both are reported; they are different reference shapes.

## Terms used in the videos

- **FRESH** — a leader bounding box from YOLO was used this frame.
- **COAST** — the leader box is missing this frame (scheduled dropout or detector miss) and the
  method keeps steering on its own *predicted* leader position (orange line). KALMAN ON coasts up
  to 3 s on its Kalman prediction (fusing last motion, own speed and leader speed); KALMAN OFF
  (production) holds its last estimate only 0.6 s; NO bbox filtering never coasts.
- **LOST** — no measurement and no prediction in use; the follower falls back to blind cruising.
- **BBOX DROPOUT (scheduled)** — a controlled test: YOLO still runs, but the leader box is
  deliberately withheld from tracking/control for 2 s, starting at t = 20 s and every 18 s
  (7 times per lap), identically for both followers and all methods. Grey bands in the plots.
- **NO bbox filtering** — production's bbox track gate is switched OFF (it normally rejects a new
  box whose horizontal position jumps > 0.45 half-image-width or whose size changes > 5× from the
  track, and prefers boxes near the prediction), and there is no smoothing, prediction or coasting.
  Each frame simply uses the largest leader-class YOLO box as-is — false positives and sudden
  switches are accepted.
- The 3-way videos (`rollout_videos_3way/`) have no title bar; the condition is in the file name
  (L01–L10 = full circle lap; W1–W4 = weather with non-fixed leader trajectory).

## How to read a rollout video

Each video shows the **left follower's camera** (exact frames the detector saw) for
each method on the **same seed**: white box = true leader (for evaluation only),
magenta box = YOLO detection the method used, orange line = where the method
believes the leader is (keeps showing during dropouts when the method predicts),
status FRESH / COAST (predicting through loss) / LOST. Under each camera: a
top-down formation map centred on the leader (red), grey rings = formation slots,
and the live formation error. Bottom-right panel: formation error of all methods
over time (log scale; grey bands = dropouts) and final RMSE.

Seed selection is fixed in advance (no cherry-picking): middle seed of the
confirmatory test for C8/C10/W1 (4409), middle of four for C0/C1/C4/C7 (4153),
first fresh seed for the other weather levels (4903). Single-seed videos
illustrate; the matrix and statistics are the evidence.

## Key results (details: `matrix/EXPERIMENT_MATRIX.md`)

**1. Confirmatory test (frozen protocol, 8 unseen seeds; huge waves + rain + clear maneuvering, all with bbox loss):**
Kalman ON reduced formation error by **69 % vs no tracker filtering** and **49 % vs production
Kalman OFF**, with every one of the 8 seeds favouring Kalman (exact p = 0.0078 each). Against a
matched non-Kalman EMA filter on the same controller the reduction (33 %, 6/8 seeds, p = 0.078)
is a trend, not confirmed.

**2. Full circle lap in every weather/wave level (2 seeds each, median RMSE / time broken > 10 m):**

| Condition | Kalman ON | Kalman OFF | No bbox filtering | Reading |
|---|---|---|---|---|
| Calm 0.55 | **2.9 m / 0 %** | 6.2 / 2 % | 5.1 / 0 % | all hold; Kalman tightest |
| Rough 1.5 | **2.5 m / 0 %** | 5.7 / 1 % | 4.7 / 0 % | all hold; Kalman tightest |
| **Huge waves 3.0** | **3.3 m / 0 %** | 117 / 28 % | 27 / 21 % | **only Kalman ON holds the whole lap** |
| Light rain 0.15 | **208 / 23 %** | 481 / 94 % | 883 / 97 % | all eventually lose the leader; Kalman holds formation ~4× longer |
| Rain 0.25 | **168 / 30 %** | 625 / 94 % | 912 / 99 % | same |
| Rain 0.4 | 609 / 77 % | 875 / 97 % | 1024 / 100 % | detector mostly blind; Kalman delays failure |
| Heavy rain 1.0, night, night + rain, dark storm | 573–1241 / 98 % | 679–1239 / 100 % | 797–1278 / 100 % | **detector blind (0 % correct detections) — every method fails; no filter can help** |

**3. Non-fixed leader trajectories (speed changes + S-turns):** same pattern — clear sea:
Kalman 4.3 m / 0 % broken vs OFF 7.4 m / 23 %; huge waves 4.7 / 8 % vs 8.4 / 28 %; rain 0.15
5.4 / 2 % vs 11.8 / 52 %; rain 0.25 6.6 / 13 % vs 156 / 80 % (n = 2).

**Counterexamples kept in the package:** tight R180 turn (EMA filter beats Kalman), unexpected
turn inside an 8 s blackout (all fail; Kalman came within 4 m), one huge-wave seed where Kalman
locked onto the other follower after a dropout (`*_KF_FAILURE_EXAMPLE.mp4`).

**What the evidence supports:** Kalman-filter fusion keeps the formation through temporary
leader-bbox loss under huge waves and light-to-moderate rain, where production Kalman-OFF and
unfiltered bboxes lose it. It does not make the formation work when the detector itself cannot see
the leader (heavy rain, night, dark storm) — that needs a better detector or another sensor.
